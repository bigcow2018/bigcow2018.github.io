机器狗 · 手势场

打开前置摄像头，用 MediaPipe 做 21 点手指追踪，把机器狗画面叠在实景上。比出 1 / 2 / 3 / 4 或左右摇手，可切换抬腿欢迎、后空翻、跳跃等动作演示。

相关实验页

更多可在浏览器里直接打开的公开实验，不是博客目录。

风扇动平衡测试

将手机竖放固定，用振动与麦克风采样做风扇动平衡监测示意：先标定基线，再根据振动或声音变化给出 OK / NG 提示。

磁场监测

读取设备磁力计，显示合成磁场 |B|、相对零点变化和三轴分量曲线。需在支持 Generic Sensor 的 Chrome 中以 HTTPS 打开。

PPG 心率示意

用后置摄像头读取画面红色分量，示意光电容积脉搏波并估算 BPM。页面标明非医疗用途，结果受按压、光线和设备影响。

手部骨骼 · 丝绸物理

网络摄像头实时 21 点手部骨骼，叠加以指尖为跟随目标的丝绸飘带物理效果，基于 MediaPipe 手部模型。
