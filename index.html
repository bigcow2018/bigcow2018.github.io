ABOUT

任瑞，机械设计实践者，关注机电实验、交互式可视化与实践教学。

正在做的事

从事机械设计工作，并在网页上做可交互的实验与教学辅助工具。已公开的实践包括机械制图识图辅助、摄像头上手势驱动的机器狗画面，以及手机 IMU、磁场、风扇动平衡等传感器实验页。

机械设计 实践教学 机电实验 可视化

为什么做这个网站

社交平台的内容可见性由算法决定。个人网站让我可以自己决定内容、结构与展示方式。课程笔记、项目记录、作品集……十年后回头看，它可能成为最珍贵的数字资产。

机器狗 · 手势场

打开前置摄像头，用 MediaPipe 做 21 点手指追踪，把机器狗画面叠在实景上。比出 1 / 2 / 3 / 4 或左右摇手，可切换抬腿欢迎、后空翻、跳跃等动作演示。

来源：公开仓库 打开演示 GitHub
DWG 02-04 STATUS / 可演示

IMU Sensor Pro Lab

手机端 IMU 实验页。读取加速度与姿态（Pitch / Roll / Yaw），用曲线图和 3D 模型同步显示设备运动。
